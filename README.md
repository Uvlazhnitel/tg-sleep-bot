# tg-sleep-bot

Personal sleep assistant chatbot focused on helping a single user wake up every day at 09:00.

## Current status

This repository currently contains the Phase 0 product specification. The bot is intended to be:

- a free-form Telegram chat assistant
- practical, concise, and non-judgmental
- science-based and explicitly non-medical
- capable of remembering useful personal context over time
